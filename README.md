# Hydration Level Prediction System
Machine Learning-based hydration prediction system built using Scikit-learn and Streamlit.

# Features
- Real-time hydration prediction
- Interactive Streamlit application
- Data preprocessing and feature engineering
- ML model prediction system

# Technologies Used
- Python
- Scikit-learn
- Pandas
- NumPy
- Streamlit

# Files
- app.py → Streamlit application
- project.py → Trained ML model
- dataset.csv → Dataset used for training

# Run Project
streamlit run app.py
